# Slides

One [Marp](https://marp.app) deck per session (Markdown in, PDF/HTML out), with the
course theme in `theme/vneo.css` (dark surface, sage accent; fonts load from Google Fonts
when online, system fonts otherwise). Figures come from `../figures/`, generated by the
solution notebooks.

Prebuilt PDFs are in [`pdf/`](pdf/). To rebuild (needs Node.js and Chrome/Chromium; the
first run downloads Marp CLI):

```bash
make slides
# which runs:
npx -y @marp-team/marp-cli@4 --theme-set slides/theme/vneo.css --pdf --allow-local-files \
    --input-dir slides --output slides/pdf
```

If Marp cannot find a browser, point it at one: `CHROME_PATH=/usr/bin/chromium make slides`.
Presenting from the Markdown directly also works with the Marp extension for VS Code
(select the theme file in its settings).
